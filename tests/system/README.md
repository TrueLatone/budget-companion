# Functional system tests

Use this directory for future pytest automation that drives a complete application workflow across component boundaries or through a deployed test interface. The [pytest guide](../README.md) covers the existing integration tests and shared fixtures.

For browser-based manual testing, follow the [Build 3 evidence workflow](../../docs/testing/results/build-3/). Use a disposable test instance and synthetic data, and record the tested commit, case IDs and session evidence.
