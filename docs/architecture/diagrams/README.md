# Architecture diagrams

The official Software Architecture Document and its embedded figures are maintained separately in restricted project storage. Use the [public architecture overview](../architecture.md) and the matching source revision when preparing diagrams for publication.

- [C4](c4/) holds reviewed context and container diagrams.
- [UML](uml/) holds reviewed logical and behavioral diagrams.
- [Database](database/) holds reviewed entity relationship diagrams.
- [Deployment](deployment/) holds reviewed diagrams of runtime nodes and connections.
