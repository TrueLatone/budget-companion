# Requirements baseline v1.2

The Vision, Use-Case Specification, and Software Development Plan all identify their v1.2 revision as **27 November 2026**. The official artifacts and embedded Use-Case Model are held in restricted project storage. These public summaries describe their technical scope and compare it with the code on `main` at `d61475d`.

- [Functional and quality requirements](functional-requirements.md) lists F01–F38 and N01–N12, with Vision priorities and Build 3 status.
- [Use-case index and model traceability](use-case-index.md) lists UC01–UC31, their feature labels, and relevant repository evidence.
- [Baseline discrepancies](baseline-review.md) records open requirements and implementation questions for Build 3 integration and PA4.
- [Release roadmap](../management/README.md) records Software Development Plan targets and Build 3/4 scope.
- [PA4 testing scope](../pa4-test-coverage-matrix.md) maps the use cases to testing workspaces. [API contracts](../architecture/api-contracts.md) and [Build 3 verification](../build3-verification.md) describe running behavior and completed checks.

**Verified** means the cited source behavior has existing automated or recorded browser coverage. **Verified core** covers the listed subset. **Source-reviewed** means implementation was inspected and the stated behavior has no dedicated check in the reviewed evidence. **Partial**, **Divergent**, **Planned**, and **Proposed** describe remaining work or discrepancies. These labels are independent of product priority and of PA4 system-test completion.
